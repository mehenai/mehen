# create-mehen

```sh
npm create mehen
```

sets [Mehen](https://mehen.dev) up on this machine, so your agent uses your API keys without ever receiving them. It is `npx @mehenai/cli up`: it installs the signed `mehen` if it is missing, then runs `mehen up`. Options after `--` are passed on: `npm create mehen -- --port 7788`.

Docs: https://docs.mehen.dev. Source: https://github.com/mehenai/mehen. Apache 2.0.
